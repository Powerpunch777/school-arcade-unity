# Screenshot provenance

The README images are unedited captures of the running **Soul Archer CMP-265 Windows build**, supplied by the project owner as `CMP-265.zip`.

Captured on **October 10, 2026 (Asia/Seoul)** by launching `SoulArcher-CMP-265.exe` and using the normal game menus, with Easy difficulty selected. These are application-window captures; they are not concept art, mockups, or images from an automated QA scene.

| File | Scene |
| --- | --- |
| `title.jpg` | Initial title menu |
| `forest-combat.jpg` | First forest combat room, shortly after the opening scenes |
| `ability-selection.jpg` | Upgrade choice reached after clearing the first room |

The interface is Korean. English explanations appear beside the images in the main README. The screenshots document this supplied build; they do not independently establish that every campaign stage or feature has been tested.

The compiled build and private QA archives are not included here. The image content remains subject to the project's existing rights and third-party asset notices.
