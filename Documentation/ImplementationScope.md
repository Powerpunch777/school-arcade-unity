# 전체 게임 구현 범위

## 연결된 흐름

타이틀 → 난이도(쉬움/보통) → 도입 컷신 3장 → 숲/동굴/마왕의 성 → 보스 → (다음 스테이지 또는 공주 구출 엔딩 2장) → 승리/패배 결과 → 전적/통계입니다.

각 스테이지는 전투방 3개, 상점방 1개, 보스방 1개를 `RoomGraph`로 유지합니다. 방문·클리어 상태는 재방문해도 보존되고 HUD 미니맵에 표시됩니다. 숲과 동굴 보스 처치 시 하트 1개를 회복하며 모르칸 처치 보상은 없습니다.

## 핵심 규칙 근거

- 정지 상태에서만 화면 안 최근접 살아 있는 적에게 자동 발사합니다.
- 플레이어는 5하트와 0.5초 무적을 가지며 쉬움은 피해를 0.5 줄이되 최소 0.5 피해를 남깁니다.
- 일반 적은 숲 늑대/독버섯, 바위 딱정벌레/수정 정령, 방패 해골병/암흑 마법사로 지역별 2종씩 분리됩니다.
- 보스는 거대 나무 정령, 거대 박쥐, 2단계 마왕 기사 모르칸이며 보스별 이동·투사체 패턴과 체력 모델을 사용합니다.
- 능력은 공격/공격 속도/관통/반사/회복/이동 속도 6종, 런당 6회 선택, 동일 능력 최대 3중첩, 카드 후보 중복 제거 및 3중첩 후보 제외를 적용합니다.
- 반사 능력은 화살이 방 경계에 닿을 때 중첩 횟수만큼 진행 방향을 반전합니다.
- 전적은 승패·난이도·시간·도달 스테이지/방·남은 하트·선택 능력만 로컬에 최근 20판 저장합니다.
