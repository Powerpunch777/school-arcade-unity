# 레온 스프라이트 납품

## 산출물

- `leon_walk.png`: 512×32 RGBA PNG, 32×32 셀 16개(8방향×2프레임)
- `arrow.png`: 16×16 RGBA PNG, 단일 셀 1개(오른쪽 기준 방향)
- `preview.png`: 512×32 RGBA PNG, 32×32 레온 걷기 셀 16개를 한 줄 배치

## 시트 배치

`leon_walk.png`는 왼쪽에서 방향별로 `정지/걷기` 2프레임씩 배치한다. 각 방향은 전체 캔버스 회전이 아닌 독립 픽셀 드로잉이다.

| 묶음 | 방향 | 셀 열 |
|---:|---|---:|
| 1 | 아래 (down) | 0–1 |
| 2 | 아래 오른쪽 (down_right) | 2–3 |
| 3 | 오른쪽 (right) | 4–5 |
| 4 | 위 오른쪽 (up_right) | 6–7 |
| 5 | 위 (up) | 8–9 |
| 6 | 위 왼쪽 (up_left) | 10–11 |
| 7 | 왼쪽 (left) | 12–13 |
| 8 | 아래 왼쪽 (down_left) | 14–15 |

`arrow.png`는 16×16 셀 안에 오른쪽을 향한 단일 기준 화살 하나만 둔다. 화살의 길이축은 수평이며 회전 중심은 셀 중앙 `(8,8)`이다. 셀 경계에 닿지 않도록 여백을 유지한다. 나무 몸통과 밝은 화살촉은 원본 크기에서 식별되어야 한다.

Unity에서는 `arrow.png`를 `Sprite (2D and UI)`로 임포트하고 `Filter Mode: Point (no filter)`, `Compression: None`, 셀 크기 `16×16`, 피벗 `Center (0.5, 0.5)`를 사용한다. 발사 시 단일 기준 이미지를 자동 조준 대상까지의 실제 이동 벡터 각도로 연속 회전하며, 화살의 진행 방향과 회전 방향을 일치시킨다. 방향별 화살 시트와 비교 이미지는 사용하지 않는다.

## 레온 프레임 기준

모든 `leon_walk.png` 셀의 공통 기준점은 `(16, 30)`이며 모든 프레임의 불투명 최하단은 `y=30`이다. `preview.png`는 레온 걷기 16프레임만 보여 주며 화살 방향 비교는 포함하지 않는다.

## 팔레트·알파 규칙

승인된 32색 마스터 팔레트 안에서만 색을 사용한다. `arrow.png`의 실제 불투명 RGB는 `#000000` `#6A4023` `#A87449` `#ECD09B`이며 투명 배경을 사용한다. 모든 PNG는 알파값 `0` 또는 `255`만 사용하고 안티앨리어싱·반투명 외곽선을 사용하지 않는다.

검증은 RGBA PNG를 읽어 크기, 셀 배치, 알파 바운딩 박스, 화살 중심축, 고유 RGB, 승인 팔레트 포함 여부와 알파값을 검사하는 방식으로 수행한다. `leon_walk.png`는 이 전환에서 변경하지 않는다. 외부 이미지·외부 API·외부 라이선스 자산은 사용하지 않았다.

## 인계

Unity 임포트 설정: `Sprite (2D and UI)`, `Filter Mode: Point (no filter)`, `Compression: None`. 실제 Unity 카메라·배경 타일 대비와 플레이 중 연속 회전 결과는 Unity에서 추가 확인한다.
