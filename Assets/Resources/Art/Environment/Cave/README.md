# 소울 아처 동굴 환경 타일 세트 — CMP-186

`committed implementation` 검수 산출물이다. `cave_rooms_preview.png`는 확정 런타임 맵이 아닌 1배 검수용 시안이며, 외곽 벽·문 조합·경로·안전 영역을 판독하기 위한 오버레이를 포함한다.

## 산출물

| 파일 | 규격 | 용도 |
|---|---:|---|
| `cave_tiles.png` | 256×192, 16×12 셀 | 16×16 동굴 타일 아틀라스 |
| `cave_rooms_preview.png` | 1920×360 | 640×360 전투방 3패널 |
| `cave_collision_guide.png` | 1024×640 | 좌표·충돌·멀티셀 외곽 가이드 |

승인된 32색 마스터 팔레트의 20색 부분집합만 사용한다. 모든 PNG는 알파 `{0,255}`(현재 산출물은 전부 255), 최근접 픽셀, 안티앨리어싱 없음이다. `SOLID`는 이동·화살 차단, `LOW COVER`는 이동 허용·화살 차단, `DECOR`는 이동·화살 허용이다.

## 아틀라스 좌표와 충돌

좌표는 `(x,y)` 셀 좌표이며 0부터 시작한다. 멀티셀은 실제 2차원 직사각형 점유로 복사한다.

| 좌표 범위 | 이름 | 방향/크기 | 분류 |
|---|---|---:|---|
| `(0,0)–(15,0)` | 기존 바닥-절벽 상단 경계 | 상단 반복 | SOLID |
| `(0,1)–(15,1)` | 동굴 벽 수직면 | 좌우 반복 | SOLID |
| `(0,7)–(15,7)` | 바닥-절벽 하단 경계 | 하단 반복 | SOLID |
| `(0,2)–(3,2)` | 닫힌 문 N/S/W/E | 1×4 | SOLID |
| `(4,2)–(7,2)` | 열린 문 N/S/E/W | 1×4 | DECOR, 통과 |
| `(0,3)–(3,3)` | 균열·자갈·광맥 | 단일 셀 | DECOR |
| `(9,3)–(15,3)` | 작은 수정·자갈·빛 반점 | 단일 셀 | DECOR |
| `(0,4)–(1,5)` | `pillar_2x2` | 2×2 | SOLID |
| `(2,4)–(3,5)` | `rock_2x2` | 2×2 | SOLID |
| `(4,4)–(5,5)` | `rubble_2x2` | 2×2 | LOW COVER |
| `(6,4)–(8,6)` | `crystal_cluster_3x3` | 3×3 | SOLID |
| `(0,8)` | 바위 바닥 기본 `floor_base` | 1×1 | DECOR |
| `(1,8)`, `(2,8)`, `(3,8)` | 저대비 바닥 변형 `floor_var_a/b/c` | 1×1 | DECOR |
| `(4,8)`, `(5,8)`, `(6,8)` | 갈라진 바닥·자갈·광맥 | 1×1 | DECOR |
| `(7,8)`, `(8,8)`, `(9,8)`, `(10,8)` | 작은 수정·자갈·균열·빛 반점 | 1×1 | DECOR |
| `(0,9)`, `(1,9)`, `(2,9)`, `(3,9)` | 바닥-절벽 상·하·좌·우 경계 `floor_cliff_t/b/l/r` | 1×1 | SOLID |
| `(4,9)–(7,9)` | 바닥-절벽 외곽 모서리 TL/TR/BL/BR | 1×1 | SOLID |
| `(8,9)–(11,9)` | 바닥-절벽 내곽 모서리 TL/TR/BL/BR | 1×1 | SOLID |
| `(12,9)`, `(13,9)`, `(14,9)`, `(15,9)` | 동굴 벽/절벽 상·하·좌·우 `wall_t/b/l/r` | 1×1 | SOLID |
| `(0,10)–(3,10)` | 동굴 벽 외곽 모서리 TL/TR/BL/BR | 1×1 | SOLID |
| `(4,10)–(7,10)` | 동굴 벽 내곽 모서리 TL/TR/BL/BR | 1×1 | SOLID |
| `(0,11)–(15,11)` | 바닥 반복 검수 스트립(변형 순환) | 1×1 | DECOR |

열린 문 셀은 순서대로 N/S/E/W `(4,2)`, `(5,2)`, `(6,2)`, `(7,2)`이며 닫힌 문 셀은 N/S/W/E `(0,2)`, `(1,2)`, `(2,2)`, `(3,2)`이다. 실제 조립 예: `pillar_2x2 = [(0,4),(1,4);(0,5),(1,5)]`, `rock_2x2 = [(2,4),(3,4);(2,5),(3,5)]`, `crystal_cluster_3x3 = [(6,4),(7,4),(8,4);(6,5),(7,5),(8,5);(6,6),(7,6),(8,6)]`. 기둥은 높고 수직적인 단면, 큰 바위는 둥글고 비대칭이며 넓은 바닥 접점으로 구분한다.

바닥 반복 검사 샘플은 `floor_base (0,8)`와 `floor_var_a/b/c (1,8)–(3,8)`를 3×3으로 반복했다. 내부 타일 접합부의 불연속·경계선은 가로 `0`, 세로 `0`이며, 변형은 기본과 같은 저대비 표면 규칙을 사용한다. 경계 조합 검수는 `(0,9)–(11,9)`의 상·하·좌·우 및 내·외곽 모서리를 5×5로 배치해 빈 픽셀 `0`, 끊김 `0`을 확인했다. 동굴 벽/절벽은 `(12,9)–(15,9)`의 상·하·좌·우와 `(0,10)–(7,10)`의 외·내곽 모서리를 별도 셀로 제공한다.

`cave_collision_guide.png`의 좌표 격자에는 README 분류를 직접 겹쳐 표시했다. SOLID 셀/스탬프 점유 외곽은 굵은 빨간 X와 실선, LOW COVER는 노란 사선, DECOR는 회색 점선 원이다. 좌표별 마커 대조 결과는 README 분류와 `0`건 불일치다.

실행 결과: PNG 크기 `256×192 / 1920×360 / 1024×640`, 아틀라스 16px 정수 격자, 셀 경계 침범 0, 빈 셀 0, 알파 `{255}`, 팔레트 외 RGB 0, 문 폭 48px, 경로-SOLID 교차 0(좁은 통로 포함), 구조물 4종 조립 crop 불일치 0, 세 승인 스프라이트 일치, guide↔README 분류 불일치 0, 바닥 3×3 가로·세로 이음선 0, 경계 5×5 빈 픽셀·끊김 0, `git diff --check` 통과.
