# 숲 보스 거대 나무 정령

## 산출물

- `ancient_tree_spirit.png`: 320×64 RGBA PNG. 64×64 셀 5개를 가로로 배치했다.
- `forest_boss_preview.png`: 640×360 검수용 비교 이미지. 숲 타일 배경 위에서 보스 5프레임을 2배 정수 확대하고 레온·숲 늑대·독버섯을 같은 2배 기준으로 배치했다. 상단과 하단의 한글 픽셀 글리프는 원본 크기 판독용이며, 비교 캐릭터 아래에 `상대 크기 비교용, 실제 보스방 배치 아님`을 표시한다.

## 셀 배치와 공통 기준

| 셀 | 프레임 | 게임 패턴 연결 |
|---:|---|---|
| 0 | 대기 1 | 기본 대기 |
| 1 | 대기 2 | 영혼 핵 맥동·가지 미세 이동 |
| 2 | 뿌리 준비 | 하단 뿌리 확장·핵 수축, 뿌리 솟구치기 예고 |
| 3 | 씨앗 준비 | 수관 씨앗 주머니 팽창·핵 집중, 씨앗 부채꼴 예고 |
| 4 | 식물 소환 준비 | 양옆 가지 상승·바닥 뿌리 원형 확산, 식물 소환 예고 |

모든 셀의 공통 피벗은 `(32, 61)`이며, 불투명 바닥선은 `y=61`이다. 중심축은 `x=32`를 기준으로 유지하고, 셀 밖으로 나가는 픽셀은 없다. 실제 공격, 투사체, 예고선, 피격 점멸과 사망 효과는 Unity 효과로 처리하며 본 시트에는 포함하지 않았다.

## 대표 색상

숲 지역 공통 마스터 팔레트에서 14색을 사용했다.

`#181D1E` 외곽선, `#2A231D` 깊은 음영, `#4C3726` 나무껍질, `#6C4C2F` 중간 나무껍질, `#916637` 밝은 나무결, `#354D2B` 이끼 음영, `#4D6E33` 잎, `#7D9741` 밝은 잎, `#B58437` 씨앗·황토, `#5B412A` 흙 뿌리, `#11595D` 핵 외곽, `#24BAB4` 핵 청록, `#91F6DA` 핵 발광, `#EBFFE2` 핵 중심.

## 검증 결과

검증 스크립트로 `ancient_tree_spirit.png`를 확인했다.

- 크기: `320×64`, 64×64 셀 나눗셈 통과
- 알파: `{0, 255}`만 사용
- 셀별 알파 바운딩 박스: `(6,8)-(58,61)`, `(6,8)-(58,61)`, `(7,7)-(58,61)`, `(7,8)-(58,61)`, `(4,8)-(60,61)`
- 셀별 바닥선: 전 프레임 `y=61`
- 셀별 불투명 픽셀 중심: `31.88`, `31.88`, `32.16`, `32.31`, `32.06`
- 인접 프레임 픽셀 차이: 대기1→대기2 `16`, 대기2→뿌리 `370`, 뿌리→씨앗 `460`, 씨앗→소환 `648`
- 고유 RGB: 셀별 11~12색, 승인 팔레트 외 RGB `0`
- 안티앨리어싱: 없음. 모든 픽셀은 불투명 또는 완전 투명

프리뷰는 `640×360`이고, 원본 숲 타일을 nearest 방식으로 반복한 뒤 보스·레온·숲 몬스터를 모두 동일한 2배 nearest 방식으로 합성했다. `검수용 비교 이미지`, `대기1`, `대기2`, `뿌리 준비`, `씨앗 준비`, `식물 소환 준비`와 상대 크기 주의 문구는 한글 픽셀 글리프로 표시했다. 프리뷰의 문구는 최종 게임 UI가 아닌 검수용 표시다.

## 출처·라이선스·Unity import

보스 스프라이트는 본 프로젝트의 승인 브리프에 맞춰 제작한 원본 픽셀 산출물이며 외부 이미지·폰트·코드를 최종 스프라이트에 포함하지 않았다. 프리뷰 배경과 비교 캐릭터는 프로젝트 내부 참조 파일 `References/Art/Environment/Forest/forest_tiles.png`, `References/Art/Player/Leon/leon_walk.png`, `References/Art/Enemies/Forest/forest_wolf.png`, `References/Art/Enemies/Forest/poison_mushroom.png`를 사용했다.

Unity에서는 `Texture Type=Sprite (2D and UI)`, `Sprite Mode=Multiple`, `Pixels Per Unit=16`, `Filter Mode=Point (no filter)`, `Compression=None`, `Generate Mip Maps=Off`로 import하고 64×64 셀 단위로 slice한다.

미검증 영역은 Unity 실제 런타임에서의 피벗·애니메이션 재생과 레온의 전투 중 상대 크기다. 본 작업에서는 PNG 구조, 한글 판독 및 정수 배율 시각 검수까지 수행했다.
