# 모르칸 최종 보스 스프라이트 시트

## 수정 반영

- Designer 피드백 반영: 모든 프레임의 대검을 넓은 칼날·분리된 손잡이로 재구성했다. 검기 준비는 뒤로 긴 검신, 연속 참격 준비는 낮은 전방 검신, 교차 검기 준비는 머리 위 수직 검신이다.
- 방패 해제는 방패를 몸통 바깥 아래로 이동해 흉갑과 붉은 핵을 가리지 않는다.
- 전환1은 균열과 어깨 이탈 시작, 전환2는 투명 틈·비대칭 방패 조각·흉갑 파손으로 단계 차이를 만든다. 2단계 대기는 방패가 완전히 없고, 망토가 몸 뒤쪽에서 아래·바깥으로 흐르는 좁은 비대칭 천 실루엣으로 정리되어 붉은 방패로 오인되지 않는다. 전면에는 투명 갑옷 틈과 붉은 마력 핵을 남겼다.

## 셀 배치와 연결

0~9 순서: 1단계 방패 대기1, 1단계 방패 대기2, 검기 준비, 방패 해제, 전환1, 전환2, 2단계 대기1, 2단계 대기2, 연속 참격 준비, 교차 검기 준비. 공통 바닥 피벗은 `(32, 62)`, 불투명 바닥 행은 y=62이며 모든 셀 경계를 침범하지 않는다. 공격 검기·참격·피격·사망 효과는 Unity에서 처리한다.
