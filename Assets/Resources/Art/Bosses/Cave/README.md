# 동굴 보스 거대 박쥐

## 산출물

- `giant_bat.png`: 384×64 RGBA PNG. 64×64 셀 6개를 가로로 배치했다.
- `cave_boss_preview.png`: 640×360 검수용 비교 이미지. 동굴색 배경에서 6프레임과 레온·바위 딱정벌레·수정 정령의 상대 크기를 같은 1배 nearest 기준으로 배치했다. `검수용 비교 이미지`와 `상대 크기 비교용, 실제 보스방 배치 아님` 안내는 검수 전용이며 실제 게임 UI가 아니다.

## 셀 배치·게임 패턴 연결

| 셀 | 프레임 | 게임 패턴 연결 |
|---:|---|---|
| 0 | 비행 대기 1 | 기본 비행 대기, 날개가 중간 높이 |
| 1 | 비행 대기 2 | 기본 비행 대기, 날개가 내려가며 몸이 2px 낮아 보임 |
| 2 | 돌진 준비 | 날개를 뒤로 접고 몸통을 좁혀 직선 돌진 예고 |
| 3 | 반사 음파 준비 | 날개를 최대한 펼치고 목 주변 청록 에너지 집중; 투사체는 Unity에서 생성 |
| 4 | 암전 자세 | 날개로 몸을 감싼 어두운 실루엣과 강한 눈 노출; 화면 암전은 Unity에서 처리 |
| 5 | 벽 충돌 기절 | 날개가 처지고 머리·몸이 기울어진 자세; 공통 비행 피벗보다 시각 중심이 3px 하강 |

모든 셀의 공통 비행 피벗은 `(32, 58)`이다. 중심축은 `x=32`를 유지했으며, 셀 경계를 침범하지 않는다. 기절 프레임의 의도된 하강은 픽셀 좌표 기준으로 머리·몸·날개를 다른 프레임보다 `+3px` 낮춘 것이다. 실제 돌진 경로, 반사 음파 투사체, 화면 암전, 피격 점멸과 사망 효과는 이미지에 굽지 않고 Unity에서 처리한다.

## 대표 색상

승인된 32색 마스터 팔레트 중 11색을 사용했다.

`#141416` 외곽선, `#2D2F33` 깊은 음영, `#2B4E8C` 날개, `#497AD3` 날개 중간톤, `#82AAFF` 눈 발광·날개 하이라이트, `#3D2314` 몸통 음영, `#6A4023` 몸통 가죽톤, `#FCDB5D` 눈·발톱 강조, `#FFE999` 눈 중심·발톱, `#8F1F2E` 암전 자세의 몸통 포인트, `#00A2A2` 음파 준비 에너지`

## 검증 결과

로컬 Pillow 픽셀 검증과 원본/정수 배율 시각 검토를 수행했다.

- `giant_bat.png`: `384×64`, 64×64 셀 나눗셈 통과
- 알파값: `{0, 255}`만 사용, 부분 알파 `0`
- 셀별 알파 바운딩 박스: `(4,8)-(60,46)`, `(3,8)-(61,46)`, `(12,8)-(52,46)`, `(2,8)-(62,46)`, `(14,8)-(50,46)`, `(6,11)-(58,51)` (좌·상 포함, 우·하 포함 표기)
- 셀별 불투명 픽셀 중심축: `32.01`, `32.01`, `32.03`, `32.01`, `32.02`, `32.01`
- 셀별 불투명 중심 y: `26.99`, `29.53`, `27.45`, `24.74`, `28.13`, `35.00`; 기절 프레임은 시각 중심이 대기1보다 `+8.01px`이며, 의도된 기준점 하강 자체는 `+3px`
- 인접 프레임 픽셀 차이: `623`, `586`, `892`, `1210`, `1141`; 대기 두 프레임도 실제 픽셀 차이가 있다
- 스프라이트 고유 RGB: `11색`, 승인 팔레트 외 RGB `0` (대조 목록: 없음; 사용 RGB는 `#141416`, `#00A2A2`, `#2B4E8C`, `#2D2F33`, `#3D2314`, `#497AD3`, `#6A4023`, `#82AAFF`, `#8F1F2E`, `#FFE999`, `#FFFFFF`)
- 셀 잘림: 없음. 모든 셀에서 x/y가 `0..63` 안에 있고 공통 축을 유지한다
- `cave_boss_preview.png`: `640×360`, 모든 프레임과 수정 정령 대표 프레임이 1배 nearest로 배치되어 잘리지 않음. 프리뷰는 비교 캐릭터 원본 팔레트까지 합쳐 고유 RGB `21색`이며 알파는 `255`만 사용한다. 수정 정령은 `crystal_spirit.png`의 첫 32×32 셀을 `(604,278)`에 그대로 합성했다.
- 프리뷰 시각 확인: 날개 폭·귀·작은 몸통·발톱·빛나는 눈과 네 특수 자세를 판독했고, 레온·동굴 몬스터보다 보스가 압도적으로 큰 비교가 보인다

## 출처·라이선스·Unity import

거대 박쥐 스프라이트는 승인된 아트 브리프와 프로젝트 마스터 팔레트에 맞춰 로컬 고정 픽셀 도형으로 제작한 원본이다. 외부 이미지·폰트·코드를 최종 스프라이트에 포함하지 않았다. 프리뷰 비교 캐릭터는 프로젝트 내부 참조 파일 `References/Art/Player/Leon/leon_walk.png`, `References/Art/Enemies/Cave/rock_beetle.png`, `References/Art/Enemies/Cave/crystal_spirit.png`의 첫 32×32 셀을 사용했다. 외부 라이선스 조건은 없다.

Unity에서는 `Texture Type=Sprite (2D and UI)`, `Sprite Mode=Multiple`, `Pixels Per Unit=16`, `Filter Mode=Point (no filter)`, `Compression=None`, `Generate Mip Maps=Off`로 import하고 64×64 셀 단위로 slice한다. 피벗은 각 셀 `(32,58)`을 기준으로 수동 지정한다.

미검증 영역은 Unity 실제 런타임에서의 애니메이션 타이밍, 보스 충돌체 크기와 카메라 배경 대비다. 본 작업에서는 PNG 구조·픽셀 규칙·정수 배율 프리뷰·한글 검수 문구를 확인했다.
