# 동굴 일반 몬스터 스프라이트

## 산출물

| 파일 | 규격 | 셀 배치 | 용도 |
|---|---:|---|---|
| `rock_beetle.png` | 96×32 RGBA | x=0 이동1, x=32 이동2, x=64 피격 | 돌진형 바위 딱정벌레 |
| `crystal_spirit.png` | 96×32 RGBA | x=0 이동1, x=32 이동2, x=64 피격 | 원거리형 수정 정령 |
| `preview.png` | 192×320 RGBA | 2배 최근접, 레온·숲 몬스터·동굴 몬스터 행 | 상대 크기와 3프레임 비교 |

모든 셀은 32×32이며 공통 피벗은 `(16, 30)`(셀 좌상단 기준, x 중앙·최하단 기준선)이다. 수정 정령은 부유 중심을 x=16에 맞추고, 이동 프레임의 부유 높이만 y 방향으로 변경했다. Unity 임포트는 `Sprite Mode: Multiple`, `Pixels Per Unit: 32`, `Filter Mode: Point (no filter)`, `Compression: None`으로 설정한다.

## 프레임 설계

- 바위 딱정벌레는 낮고 넓은 돌 갑각, 전방 뿔·큰턱, 네 다리와 돌 조각 하이라이트를 사용했다. 이동1/이동2는 다리 교대와 갑각의 1픽셀 상하 변화를 사용한다. 피격은 몸통을 낮고 짧게 압축하고 다리를 접어 뒤로 밀린 자세를 구분한다.
- 수정 정령은 청록-청색 수정 핵, 밝은 중심광과 분리된 회색 파편을 사용했다. 이동1/이동2는 핵과 파편의 부유 높이를 달리한다. 피격은 핵을 기울여 낮추고 파편을 안쪽으로 모았다.
- 별도 공격·사망 프레임은 포함하지 않는다. 공격 방향은 Unity 예고선과 투사체 회전으로 전달하며, 피격 프레임에는 흰색 점멸을 굽지 않았다.

## 팔레트·알파·제작

승인된 마스터 팔레트에서 8색(딱정벌레)과 7색(정령)을 사용했다. 전체 기준 팔레트는 `#000000 #141416 #2d2f33 #575d65 #8e98a5 #ffffff #e8d5b7 #2b4e8c #497ad3 #82aaff #3d2314 #6a4023 #a87449 #ecd09b #fcdb5d #ffe999 #ffd4c0 #4a1525 #8f1f2e #d9383a`이다. 수정의 청록 인상은 승인된 청색 계열(`#497ad3`, `#82aaff`)과 흰색 중심광으로 표현했다.

형태 방향은 `imagegen` 스킬의 생성 시안으로 탐색했으며, 최종 산출물은 로컬 고정 팔레트·정수 좌표 픽셀 드로잉으로 제작했다. 생성 시안은 프로젝트 파일로 복사하지 않았다. 외부 이미지·폰트·서비스 자료를 사용하지 않아 별도 제3자 라이선스가 없다.
