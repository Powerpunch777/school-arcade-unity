# 소울 아처 UI 아트 패키지 — CMP-198

`committed implementation` 단계의 Unity 2D UI 픽셀 아트 패키지다. 출력은 승인된 32색 마스터 팔레트와 기존 숲·레온 산출물에 맞춰 Pillow의 정수 좌표 드로잉으로 제작했다. UI 스프라이트와 아이콘에는 한글 이름·수치·가격을 굽지 않았으며, 카드와 상품 패널의 중앙·하단 가로선은 Unity 텍스트를 올릴 안전 영역 표시다.

## `panel_states.png` 좌표와 안전 영역

48×64 셀을 왼쪽부터 `basic`, `focus`, `disabled`, `confirmed` 순서로 사용한다. 각 셀의 테두리는 1픽셀, 아이콘 영역은 대략 `x=16..31, y=7..22`, 텍스트 안전 영역은 `x=8..39, y=30..55`다. 포커스는 금색 테두리와 좌우 화살표를 함께 사용하며, 구매불가는 어두운 패널·잠금·대각선 차단 표시를 함께 사용한다. 선택/판매완료는 밝은 금색 체크 배지와 청색 패널을 함께 사용한다.

## Unity import

- `Texture Type`: `Sprite (2D and UI)`
- `Sprite Mode`: 아틀라스는 `Multiple`, 단일 아이콘 스트립은 `Multiple`
- `Pixels Per Unit`: 16 (`panel_states.png`는 16 기준으로 48×64 셀을 슬라이스)
- `Filter Mode`: `Point (no filter)`
- `Compression`: `None`
- `Generate Mip Maps`: 꺼짐
- `Mesh Type`: `Full Rect`
- `Read/Write`: 꺼짐
- 스프라이트 피벗: 아이콘·HUD 셀은 중앙 `(0.5, 0.5)`
- 카드/상품 패널: `panel_states.png`를 48×64로 슬라이스하고 `Image Type: Sliced`를 사용한다. 9-slice border는 좌·상·우·하 각 4px, 중앙은 텍스트 안전 영역으로 둔다.
- 640×360 미리보기는 내부 해상도 검수용이며 Unity에서 축소하지 않고 1920×1080에 3배 정수 확대한다.

## 팔레트·출처·라이선스

모든 신규 불투명 픽셀은 승인된 32색 마스터 팔레트 안에 있다. 이번 산출물에 실제 사용한 색상은 `#000000 #123C24 #141416 #216C3E #2B4E8C #2D2F33 #3D2314 #43AF6B #497AD3 #4A1525 #575D65 #6A4023 #82AAFF #8E98A5 #8F1F2E #A87449 #D9383A #E59A7A #E8D5B7 #ECD09B #FCDB5D #FFD4C0 #FFE999 #FFFFFF`다. 스프라이트는 외부 이미지·외부 API·외부 라이선스 자산 없이 로컬 Pillow 픽셀 드로잉으로 제작했다. 미리보기 배경은 승인된 `References/Art/Environment/Forest/forest_preview.png`, 캐릭터는 승인된 `References/Art/Player/Leon/leon_walk.png`를 최근접 합성했으며, 합성 전후 모든 불투명 픽셀을 마스터 팔레트에 스냅했다.

기존 단일 화살 원본 `References/Art/Player/Leon/arrow.png`는 수정하지 않았다. 작업 전후 SHA-256 표본은 `8c497a0d4d1858c1cd0a7e2af6c4a33b170eb4b3206de48c8f2d9724c1a074cd`다.

## 검수 범위

Pillow로 모든 PNG의 크기·RGBA 모드·셀 정렬·알파값·불투명 RGB 팔레트를 확인했다. 신규 아이콘·패널·HUD 스프라이트는 알파 `0/255`만 사용하고, 640×360 미리보기는 불투명 팔레트 픽셀로 저장했다. 실제 Unity 임포트와 마우스/키보드 입력 연결은 구현 저장소에서 추가 검수해야 한다.
