## 제작·출처

- 배경 탐색 시안: 내장 `imagegen` 도구로 생성한 픽셀아트 환경 이미지 6종.
- 최종 장면: 배경을 640×360으로 nearest-neighbor 축소한 뒤 승인 팔레트로 매핑하고, `References/Art/CharacterStyleSheetV2/`의 `leon.png`, `elia.png`, `morkan.png`를 nearest-neighbor 3배/2배로 합성했다.
- 생성 시안은 프로젝트 산출물로 복사하지 않았으며, 최종 납품물은 이 폴더의 PNG만 사용한다.
- 외부 이미지·폰트·상표·문자·로고를 사용하지 않았다. 생성 이미지의 별도 제3자 라이선스 표기는 없으며, 게임 내부 사용을 위한 프로젝트 제작 시안으로 관리한다.

## 팔레트·알파 검증 기준

최종 PNG의 불투명 RGB는 V2 README에 승인된 아래 20색의 부분집합/합집합만 사용한다. 이는 승인된 32색 마스터 팔레트 중 현재 V2에서 규정된 값이다.

`#000000` `#141416` `#2d2f33` `#575d65` `#8e98a5` `#ffffff` `#e8d5b7` `#2b4e8c` `#497ad3` `#82aaff` `#3d2314` `#6a4023` `#a87449` `#ecd09b` `#fcdb5d` `#ffe999` `#ffd4c0` `#4a1525` `#8f1f2e` `#d9383a`

최종 이미지 생성 후 모든 RGB를 위 팔레트에 다시 매핑했으며, 불투명 장면은 알파 `255`만 사용한다. 오버레이는 알파 `0` 또는 `255`만 사용하며 부분 투명 픽셀과 안티앨리어싱 외곽선을 만들지 않았다.

## 타이틀 오버레이 인계

- 시트 방향: 세로, 셀 크기 `640×360`.
- 프레임 0: `y=0..359`, 프레임 1: `y=360..719`, 프레임 2: `y=720..1079`.
- Unity Sprite Editor에서 `640×360` 고정 셀 3개로 Slice하고, 재생 속도는 `2 FPS`(프레임당 0.5초)로 시작한다.
- Overlay는 타이틀 배경과 동일한 원점 `(0,0)`, 스케일 `(1,1)`, 회전 `0°`로 정렬한다.
- 바람 요소 표본 좌표(각 셀의 로컬 좌표)는 `(470,148)`, `(522,112)`, `(574,178)`, `(606,88)`, `(530,246)`이며 프레임마다 정수 `+8px` 이동한다. 레온 망토 바람 스트로크는 `(493,258)` 부근에 있다.
- 본 시트는 월드 우측의 낮은 밀도 요소만 포함해 좌측 로고·메뉴 가독성을 침범하지 않는다.

## Contact sheet

`contact_sheet.png`는 각 칸을 원본 640×360 크기 그대로 배치한 3×3 시트다. 좌상단부터 6개 장면을 순서대로 배치하고, 좌하단 칸은 `title_background.png`에 오버레이 프레임 0을 적용한 검수 예시다. 나머지 두 칸은 검수용 빈 패널이다.

## Unity 인계

- 각 640×360 장면과 타이틀 배경: `Sprite (2D and UI)`, `Filter Mode: Point (no filter)`, `Compression: None`, Pixels Per Unit은 프로젝트 기본값에 맞춘다.
- `title_wind_overlay.png`: `Sprite Mode: Multiple`, `Filter Mode: Point (no filter)`, `Compression: None`, `640×360` 고정 셀로 Slice한다.
- 장면에는 UI 텍스트를 직접 넣지 않고, 컷신 문장은 별도 UI가 `y=296..359`에 표시한다.
