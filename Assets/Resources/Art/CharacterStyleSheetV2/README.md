# 소울 아처 핵심 캐릭터 스타일 시트 V2

## 제작 상태

`exploration` 단계의 재제작 시안이다. 기존 `References/Art/CharacterStyleSheet/` 파일은 보존하고, 본 폴더에만 V2 결과를 작성했다.

## 변경 목표와 반영점

- 레온과 엘리아는 32×32 안에서 머리를 7~8픽셀 높이로 줄이고, 어깨·허리 폭을 좁혀 세로 비율을 높였다.
- 팔을 몸통에서 한 칸 이상 분리하고, 다리 사이 투명 간격과 부츠를 두어 머리·몸통·팔·다리가 따로 읽히게 했다.
- 레온은 파란 망토를 양쪽으로 길게 떨어뜨리고 갈색 가죽 조끼·벨트·나무 활·화살통을 분리했다.
- 엘리아는 흰 드레스의 긴 세로 주름, 금색 왕관·허리 가장자리와 파란 가슴 보석을 별도 픽셀 군으로 만들었다.
- 모르칸은 64×64에서 머리와 흉갑을 작게 유지하고 다리를 길게 뽑았다. 붉은 망토는 뒤로 분리하고, 대검과 방패를 몸통 가까이 세워 전체 알파 바운딩 폭을 기존 52px에서 49px로 줄였다(수정본 전체 알파 bbox x=9..57, 폭 49px).
- 기존의 넓은 단일 색 덩어리 대신 외곽선, 중간톤, 하이라이트를 장비 경계에만 사용해 픽셀 노이즈를 제한했다.

## 산출물

| 파일 | 규격 | 용도 |
|---|---:|---|
| `leon.png` | 32×32 RGBA PNG | 레온 정면 대기 |
| `elia.png` | 32×32 RGBA PNG | 엘리아 정면 대기 |
| `morkan.png` | 64×64 RGBA PNG | 모르칸 정면 대기 |
| `comparison.png` | 256×160 RGBA PNG | 동일 2배 정수 확대 및 바닥선 정렬 비교 |

`comparison.png`는 세 캐릭터에 동일하게 2배 최근접 표시 배율을 적용했다(레온·엘리아 64×64, 모르칸 128×128의 표시 셀). 실제 표시된 불투명 바운딩 크기는 레온 42×56px, 엘리아 28×58px, 모르칸 98×120px로 각 원본 알파 바운딩 크기의 정확히 2배이며, 배치 기준점은 각각 레온 `(17,75)`, 엘리아 `(89,75)`, 모르칸 `(128,13)`이다. 세 확대 캐릭터의 마지막 불투명 행은 y=136이며 골드 바닥선도 y=136이다. 캔버스는 256×160이다. 게임 임포트 시 각 개별 PNG는 `Sprite (2D and UI)`, `Filter Mode: Point (no filter)`, `Compression: None`으로 설정한다.

## 사용 색상

현재 제안된 32색 마스터 팔레트 중 아래 20색만 사용했다. 세 캐릭터 PNG(`leon.png`, `elia.png`, `morkan.png`)의 실제 RGB 합집합도 20색이며, 모든 색상은 불투명 RGB 픽셀로 기록했다.

## 검증 기록

- README `사용 색상` 섹션 재검증: HEX 20개, 팔레트 외 색상 0개, `CMP-175` 포함.
- `leon.png`: 32×32, 고유 RGB 9색, 알파값 `{0,255}`, 불투명 픽셀 450개, 알파 바운딩 박스 `(6,3)-(26,30)`(좌·상 포함, 우·하 제외; 21×28px).
- `elia.png`: 32×32, 고유 RGB 8색, 알파값 `{0,255}`, 불투명 픽셀 250개, 알파 바운딩 박스 `(9,2)-(22,30)`(14×29px).
- `morkan.png`: 64×64, 고유 RGB 8색, 알파값 `{0,255}`, 불투명 픽셀 1,876개, 알파 바운딩 박스 `(9,2)-(58,62)`(49×60px). 따라서 전체 알파 바운딩 폭은 `49px < 52px`이다.
- 세 캐릭터 PNG 모두 부분 알파 0개, 안티앨리어싱 픽셀 0개, 팔레트 외 RGB 0개다.
- 기존 `CharacterStyleSheet`의 동일 파일과 픽셀 바이트 비교 결과: `leon.png`, `elia.png`, `morkan.png` 모두 `same=False`.
- `comparison.png`: 256×160, 알파값 `{0,255}`, 세 캐릭터 모두 동일 2배 최근접 정수 표시, 표시 바운딩 크기 레온 `42×56px`, 엘리아 `28×58px`, 모르칸 `98×120px`, 확대 불투명 최하단 y=136, 공통 바닥선 y=136.
- 기존 대비 실제 불투명 바운딩 박스: 레온 `27×28px → 21×28px`, 엘리아 `30×28px → 14×29px`, 모르칸 `52×57px → 49×60px`.
- 생성 도구: Image Generation 스킬 지침을 검토했으며, 기존 픽셀 자산의 정확한 팔레트·알파·배율 보존이 필요한 수정이므로 최종 변경은 로컬 고정 팔레트/최근접 픽셀 편집으로 수행했다. 참고 시안은 프로젝트 산출물로 복사하지 않았다.

## 남은 검토 사항

원본 1:1 크기에서 장비 식별성과 세로 실루엣은 확인했지만, 실제 Unity 카메라·배경 타일 위의 대비와 모르칸 방패가 전투 판정 크기와 잘 맞는지는 아직 미검증이다. 다음 검토자는 **Designer (CMP-175)** 이다.
